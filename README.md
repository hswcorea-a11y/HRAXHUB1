# HRAXHUB — HR 대시보드

경영진용 HR 지표 대시보드입니다. 한 화면의 아이콘을 누르면 상세 데이터 화면이나 외부 문서(보고서)로 이동합니다.
**모든 수치는 가상 샘플 데이터입니다** (가상 회사 "한빛그룹", 약 1,200명, 기준일 2026-10-31).

## 화면 구성

| 아이콘 | 동작 | 내용 |
|---|---|---|
| 인원 현황 | 상세 화면 | 월말 인원 추이, 부문·본부별 인원, 직급별 인원, 고용 형태 |
| 입·퇴사 / 퇴직률 | 상세 화면 | 월별 입·퇴사, 월 퇴직률 추이, 조직별 퇴직률, 퇴사 사유, 근속기간별 퇴사 |
| 조직도 | 상세 화면 | 부문 → 본부 → 팀 트리, 조직장, 팀별 인원 |
| 인력 구성 | 상세 화면 | 성별, 연령대, 근속연수, 직급별 구성 |
| 채용 현황 | 상세 화면 | 채용 퍼널, 진행 단계, 진행 중인 포지션 목록 |
| 월간 인사보고서 | 외부 링크 | `reports/` 의 엑셀 파일 (실제 PPT·드라이브 주소로 교체 가능) |

상세 화면 위쪽의 **조직 필터**(전체 / 경영지원 / 영업 / 연구개발 / 생산)로 부문별로 볼 수 있고,
각 차트의 **표로 보기** 버튼으로 숫자 표를 볼 수 있습니다. 우측 상단 버튼으로 밝은/어두운 화면을 바꿉니다.

## 지표 정의

- **월 퇴직률** = 해당 월 퇴사자 ÷ 월평균 인원(전월 말·당월 말 평균)
- **연환산 퇴직률** = 최근 12개월 퇴사자 ÷ 13개 월말 인원의 평균
- **자발적 퇴직률** = 최근 12개월 자발적 퇴사자 ÷ 위와 같은 평균 인원
- **평균 채용 소요일** = 공고 오픈부터 입사 확정까지 (부문별 입사자 수로 가중 평균)

## 파일 구조

```
index.html            페이지
assets/config.js      아이콘(타일) 목록과 외부 링크 ← 여기서 링크를 바꾸세요
assets/data.js        샘플 데이터 (자동 생성)
assets/charts.js      SVG 차트 (외부 라이브러리 없음)
assets/app.js         화면 구성과 지표 계산
assets/style.css      스타일
scripts/generate-data.mjs   샘플 데이터 생성기
scripts/make-report.py      샘플 월간 보고서(엑셀) 생성기
reports/              보고서 파일
```

## 자주 하는 수정

**외부 링크 바꾸기 / 링크 아이콘 추가** — `assets/config.js`의 `tiles`에서 `href`를 바꾸거나 항목을 추가합니다.

```js
{ id: 'groupware', type: 'link', icon: 'file', title: '그룹웨어', desc: '전자결재 바로가기', href: 'https://...' },
```

**샘플 데이터 다시 만들기**

```bash
node scripts/generate-data.mjs
python3 scripts/make-report.py   # openpyxl 필요
```

## 로컬에서 보기

`index.html`을 브라우저로 바로 열어도 동작합니다. 또는:

```bash
python3 -m http.server 8000
```
